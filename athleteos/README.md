# AthleteOS 🏆

Plataforma de gestão esportiva inteligente e integrada.

## Tech Stack
- Frontend: Next.js, Tailwind CSS
- Backend: Supabase, Node.js
- Automação: n8n
- AI: Gemini AI
- Monorepo: Turborepo, pnpm

## Monorepo Structure
- `apps/`: Next.js applications
- `packages/`: Shared libraries and configuration
- `workflows/`: n8n automations

## Setup Instructions
1. Install dependencies: `pnpm install`
2. Start development: `pnpm dev`

## Available Scripts
- `pnpm dev`: Start development servers
- `pnpm build`: Build the project
- `pnpm lint`: Run linting
- `pnpm test`: Run tests

## Security & LGPD
AthleteOS follows strict data protection guidelines compliant with LGPD. All sensitive data must be handled through secure, encrypted channels.
